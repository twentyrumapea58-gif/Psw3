# Simulasi Review Kode - Branch fitur-petunjuk

1. Tujuan Perubahan
Memperjelas petunjuk formulir pada file `daftar.html` agar pengguna memahami format pengisian yang benar.

2. Cara Pengujian
1. Buka `daftar.html` menggunakan Live Server di browser.
2. Periksa kolom formulir pendaftaran.
3. Pastikan petunjuk format sudah terlihat jelas.

3. Catatan Reviewer & Tindak Lanjut
- Komentar: Format petunjuk pada form sudah sesuai dan informatif.
- Tindak Lanjut: Disetujui dan digabung ke branch utama.
