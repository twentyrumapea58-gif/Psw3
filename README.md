# Komunitas Web Mahasiswa

## Tujuan
Membuat halaman web kegiatan mahasiswa dengan navigasi,
kartu kegiatan, tabel jadwal, dan formulir pendaftaran.

## Cara Menjalankan
1. Buka folder proyek di VS Code.
2. Jalankan index.html menggunakan Live Server.
3. Buka halaman di browser.
4. Uji navigasi, tombol salam, dan formulir.

## Perubahan
- Menambahkan navigasi ke bagian jadwal.
- Menambahkan petunjuk pada formulir.
- Menambahkan validasi input.
- Memperbaiki tampilan kartu dan tabel.
- Menambahkan desain responsif.

## Hasil Pengujian
Isi berdasarkan pengujian yang benar-benar dilakukan.
Catat hasil aktual dan bukti screenshot.

## Batasan
Data pendaftaran belum disimpan ke server.
Jadwal kegiatan masih menggunakan data contoh.

## AI Use Statement
AI digunakan untuk membantu memahami struktur HTML,
CSS, JavaScript, validasi formulir, dan Git.
Kode diperiksa kembali dan diuji di browser.
Bagian yang belum diuji tidak dinyatakan berhasil.
